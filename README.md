# clase10-final

App Android desarrollada con Kotlin y Jetpack Compose como proyecto de la clase 10.

## Tecnologías

- Kotlin y Jetpack Compose (Material 3)
- Navigation Compose
- Room (base de datos local)
- Retrofit y Gson (consumo de API)
- Coil (carga de imágenes)

## Cómo ejecutarlo

1. Clonar el repositorio.
2. Abrirlo con Android Studio.
3. Esperar a que Gradle sincronice las dependencias.
4. Ejecutar la app en un emulador o dispositivo con Android 7.0 (API 24) o superior.
